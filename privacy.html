Privacy policy

Pen2Vault · Last updated 17 October 2026

Pen2Vault is a personal tool used only by its author, Niall Piggot, on his own Google account. This policy explains what it does with Google user data.

Data it accesses

With the Gmail scope https://www.googleapis.com/auth/gmail.modify, Pen2Vault:

  • searches for emails sent from my@remarkable.com to one dedicated address of mine that have a PNG image attached;
  • reads those messages' headers (sender, recipient, date, subject and Gmail's authentication results) to confirm they are genuine shares from my reMarkable tablet;
  • downloads their PNG attachments;
  • creates the labels pen2vault/done and pen2vault/error and applies them to messages it has processed.

It does not send email, delete email, or act on any other messages.

How the data is used

Downloaded page images are transcribed into text by a model that runs entirely on my own computer. The resulting notes are saved to my local Obsidian notes folder. Copies of the page images and draft transcriptions are kept on the same computer and may be used to improve that same personal handwriting model, which runs only on my computer and is not shared or offered to anyone else.

Storage and sharing

  • All data is processed and stored only on my own computer. Nothing is sent to any server other than Google's Gmail API.
  • No data is sold, shared, or transferred to third parties, and none is used for advertising.
  • The OAuth token is stored in a local file that only my user account can read.

Google API Services User Data Policy

Pen2Vault's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from Google Account → Third-party apps & services. Locally stored images, notes and the token can be deleted by removing the files from my computer.
