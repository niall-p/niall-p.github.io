Pen2Vault

A personal tool that turns handwritten notes into Obsidian notes.

Pen2Vault is a private project with one user: its author. It is not a public service, and no one else can sign up.

What it does

  1. I write notes on a reMarkable tablet and share a page by email to my own Gmail address.
  2. Pen2Vault, running on my own computer, uses the Gmail API to find those emails and download the attached page image.
  3. A handwriting-recognition model running locally on the same computer transcribes the page to Markdown.
  4. The note is saved into my Obsidian notes folder, and the email is labelled as processed.

Google account access

Pen2Vault asks for the Gmail scope gmail.modify, which lets it read messages and change their labels. It only acts on emails sent from reMarkable's sharing service to a dedicated address of mine. It never sends or deletes email, and nothing it reads leaves my computer. See the privacy policy for details.
